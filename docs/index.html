01 / CAPACIDADES

Visual evidence.
Not opinion.

El sistema registra puntuaciones de identidad, estabilidad temporal, coherencia geométrica, estética heurística y mapas de materiales. Mantiene separados el protocolo de evaluación y las fuentes de imagen. Las métricas ilustrativas no equivalen a una evaluación científica de un modelo real.

03 / EJECUCIÓN REAL

Un contrato, de principio a fin.

La simulación incluida funciona sin GPU. Produce tres secciones de resultados y permite consumir exactamente ese archivo en el comparador y los exportadores, con semilla fija para reproducciones compatibles.

TERMINAL / LCBSYNTHETIC MODE
python -m pip install -e ".[dev]"
lcb run --characters 3 --environments 2 \
  --materials 3 --seed 42 --output demo.json
lcb report demo.json --format html
lcb report demo.json --format csv
lcb compare demo.json demo.json

La simulación no es evidencia de calidad de una IA.

El modo local incluido utiliza ruido determinista y extractores sintéticos. Para evaluar modelos reales hay que conectar funciones reales de generación y métricas validadas, fijar las condiciones del experimento y publicar limitaciones. No se anuncian puntuaciones científicas ni victorias de modelos sin datos.
